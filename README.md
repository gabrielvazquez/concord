# CONCORD

Chat, voz e transmissão de tela entre amigos, no estilo Discord.

**Acesse:** https://gabrielvazquez.github.io/concord/

- Canais de texto em tempo real
- Salas de voz com câmera e microfone
- Transmissão de tela em até 1080p 60 fps, com áudio
- Entrada só com apelido; convite por código ou link (`#CODIGO`)

Funciona melhor no Chrome ou no Edge do computador. A conexão é direta entre os participantes (WebRTC), ideal para grupos de até 5–6 pessoas. O backend (mensagens, canais e sinalização) usa o Supabase.
